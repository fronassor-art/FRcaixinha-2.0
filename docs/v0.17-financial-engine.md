# v0.17 — Motor Financeiro Completo

## Fluxo
1. Admin aprova a solicitação.
2. O sistema gera parcelas mensais com vencimentos reais, uma por mês.
3. Admin libera o empréstimo: `POST /api/loans/{id}/release`.
4. A liberação gera um débito idempotente no Ledger (`LOAN_DISBURSEMENT`).
5. O worker diário atualiza parcelas vencidas com a taxa configurada em `LOAN_DAILY_PENALTY_RATE`.
6. O participante cria Pix para o saldo atualizado da parcela.
7. Webhook confirmado baixa a parcela, registra o crédito no Ledger e verifica quitação do empréstimo.
8. Quando todas as parcelas estão pagas, o empréstimo passa para `PAID`.

## Penalidade
A taxa diária padrão é `0.00`. Isso é intencional: não existe uma taxa universal que o sistema deva assumir como automaticamente válida. Configure somente depois de validar contrato e regras aplicáveis.

## Idempotência
A liberação e os pagamentos confirmados verificam referências únicas no Ledger. O Pix continua usando `X-Idempotency-Key` no Mercado Pago.
