## Antes do deploy
- DNS e TLS conferidos.
- `.env.production` sem segredos.
- arquivos de `ops/secrets/` com modo 600.
- credenciais de teste do Mercado Pago disponíveis para homologação.
- janela de manutenção registrada.

## Teste controlado

2. backup
3. deploy
4. health/readiness
5. smoke HTTPS
6. simulador de Webhook
7. assinatura inválida → 401
8. assinatura expirada → 401
9. evento repetido → `duplicate=true`, sem novo lançamento
10. verificar Ledger
11. verificar worker/alertas
12. restore em ambiente separado

## Não fazer
- não colocar token do Mercado Pago no Git;
- não usar conta bancária pessoal para custódia;
- não liberar dinheiro real antes do Go/No-Go;
- não fazer rollback de aplicação ignorando migrations;
- não considerar Prometheus/Grafana como fonte de verdade financeira.
