# v0.22 — Observabilidade e Operação

## Stack
- **Prometheus**: coleta de métricas e avaliação das regras.
- **Alertmanager**: agrupamento, deduplicação, silenciamento, inibição e roteamento.
- **Grafana**: dashboard operacional.
- **API `/metrics`**: métricas HTTP e financeiras operacionais.
- **Worker heartbeat**: heartbeat compartilhado via Redis para monitorar o processo separado da API.

## Alertas
- API indisponível
- HTTP 5xx > 5%
- P95 > 1,5 s
- Worker sem heartbeat por mais de 3 minutos
- Parcelas vencidas

## Segurança
Prometheus, Alertmanager e Grafana ficam apenas na rede interna do Compose e não são publicados pelo Nginx. Configure autenticação/secret do Grafana e receivers reais do Alertmanager antes de produção.

## Métricas financeiras
Métricas servem para observabilidade e operação. O **Ledger continua sendo a fonte de verdade financeira**; não use Prometheus para saldos, cobrança ou contabilidade.

## Validação
```bash
python -m pytest -q
curl http://localhost:8000/metrics
```

O Alertmanager agrupa e deduplica alertas antes de encaminhá-los aos receivers. Isso reduz ruído em incidentes e permite silences/inhibition. Consulte a documentação oficial do Prometheus/Alertmanager.
