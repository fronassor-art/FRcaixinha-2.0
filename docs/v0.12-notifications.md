# FRcaixinha 2.0 — v0.12 Notificações

## Canais
- IN_APP: notificações persistidas no banco e exibidas no aplicativo.
- EMAIL: envio SMTP opcional.
- BOTH: persistência no app + tentativa de envio por e-mail.

## Eventos
- WELCOME
- LOAN_DECISION
- PAYMENT_CONFIRMED
- INSTALLMENT_DUE
- INSTALLMENT_OVERDUE

## Endpoints
- `GET /api/notifications`
- `GET /api/notifications?unread_only=true`
- `POST /api/notifications/{id}/read`
- `POST /api/notifications/read-all`
- `GET /api/notifications/admin`
- `POST /api/notifications/admin/{id}/retry`
- `POST /api/notifications/admin/run-reminders?days_ahead=3`

## E-mail
Configure `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` e `SMTP_STARTTLS` no `.env`.
O token/credencial do Mercado Pago continua somente no backend.

## Produção
Para tarefas recorrentes (ex.: lembretes diários), o endpoint `run-reminders` deve ser acionado por um worker/scheduler confiável. O FastAPI também oferece `BackgroundTasks` para tarefas pequenas após a resposta; para processamento distribuído/mais pesado, a própria documentação recomenda uma fila/worker dedicado.
