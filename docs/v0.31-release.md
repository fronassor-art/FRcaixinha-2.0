# v0.31 Release — Piloto Controlado

Version: 0.31.0

Esta release não significa autorização para operar dinheiro real. Ela adiciona controles e artefatos para executar um piloto fechado, reversível e auditável.

### Artefatos
- `scripts/pilot_v031.sh`: gate inicial e relatório do piloto.
- `scripts/pilot_reconciliation_v031.py`: reconciliação decimal de evidências exportadas.
- `pilot-reconciliation.example.csv`: modelo sem dados reais.
- `docs/v0.31-piloto-controlado.md`: plano e critérios.

### Política
O modo padrão é `sandbox`. O script bloqueia `PILOT_MODE=production` para evitar promoção acidental. Qualquer promoção posterior deve passar pelos gates da release anterior e pela aprovação operacional/jurídica.
