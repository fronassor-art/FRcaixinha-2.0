# v0.18 — Testes de integração e Sandbox

## Objetivo

Criar um caminho reproduzível para testar o ciclo financeiro antes de qualquer uso de credenciais de produção.

## Proteções

- O mock de Mercado Pago é isolado e não movimenta dinheiro.
- Nenhum Access Token real deve entrar no repositório.
- O teste deve usar banco separado (`frcaixinha_test`).
- O ambiente sandbox não deve ser publicado na internet.

## Mercado Pago real

Para validar a integração real, use as credenciais de teste fornecidas pelo Mercado Pago. A documentação oficial descreve contas/credenciais de teste e testes de Pix; Webhooks também podem ser configurados com URL de teste. Consulte a documentação oficial antes de executar a validação externa.

## Critérios de aceite

- Nenhuma operação financeira duplicada após retry.
- Webhook repetido não duplica Ledger.
- Pagamento pendente não baixa parcela.
- Pagamento aprovado baixa somente o valor devido.
- Empréstimo só é marcado como quitado após todas as parcelas.
- Auditoria registra operações administrativas.
