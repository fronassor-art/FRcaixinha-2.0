# v0.14 — Android definitivo

A v0.14 transforma o diretório `mobile/` em um projeto Android Flutter com estrutura nativa de build, Manifest, Activity Kotlin, Gradle, recursos de ícone e configuração de release.

## Build

`flutter build appbundle --release` é o formato preferido para publicação na Play Store; APK continua disponível para distribuição direta.

## Segurança

Segredos de assinatura não fazem parte do projeto. `API_URL` deve ser injetada no build e não deve conter tokens privados. O Access Token do Mercado Pago permanece exclusivamente no backend.
