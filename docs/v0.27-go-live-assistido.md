# FRcaixinha 2.0 — v0.27 Go-Live Assistido

Objetivo: transformar a release auditada em um procedimento operacional reproduzível para colocar o ambiente de produção no ar sem colocar credenciais reais no repositório.

## Ordem obrigatória
1. DNS apontando para o servidor.
2. TLS válido para o domínio.
3. Criar os arquivos em `ops/secrets/` com permissões 600.
4. Preencher `.env.production` apenas com configuração não secreta.
5. Executar `./scripts/go_live_v027.sh preflight`.
6. Fazer backup antes da primeira migração de produção.
7. Executar `./scripts/go_live_v027.sh deploy`.
8. Executar `./scripts/go_live_v027.sh smoke`.
9. Confirmar webhook HTTPS do Mercado Pago e observar logs/alertas.
10. Só então liberar o aplicativo para usuários reais.

## Mercado Pago
Use credenciais de produção somente no servidor. O token e o segredo do webhook entram por Docker Secrets. O webhook deve apontar para o domínio HTTPS público configurado para a API.

## Rollback
Rollback de aplicação deve preservar o banco. Antes de voltar a uma imagem anterior, avaliar as migrations executadas. Nunca restaurar um backup sobre produção sem validar o ponto de recuperação e registrar a operação.
