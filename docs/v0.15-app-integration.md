# v0.15 — Integração completa do aplicativo

## Objetivo
Unificar a navegação Android, autenticação, estado de sessão e acesso ao backend em uma estrutura de rotas e repositório.

## Fluxos
- Login -> Dashboard
- Dashboard -> Contribuições -> Pix
- Dashboard -> Empréstimos -> Solicitação -> Detalhes/parcelas
- Dashboard -> Extrato
- Dashboard -> Notificações
- Dashboard -> Perfil
- Admin -> painel administrativo

## Arquitetura mobile
- `AppState`: sessão e estado global mínimo
- `AppRepository`: acesso aos endpoints do backend
- `go_router`: rotas declarativas e proteção de autenticação
- telas separadas da camada de dados

## Observação
O pagamento de parcelas de empréstimos ainda depende de um endpoint específico de cobrança/Pix de parcela. A v0.15 exibe o ciclo e o saldo das parcelas sem fingir que uma parcela foi paga.

## Build
```bash
cd mobile
flutter pub get
flutter analyze
flutter test
flutter build apk --release --dart-define=API_BASE_URL=https://SEU-DOMINIO/api
```
