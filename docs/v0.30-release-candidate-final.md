# FRcaixinha 2.0 — v0.30 Release Candidate Final

## Objetivo
Consolidar as entregas v0.25–v0.29 em uma release candidata final, sem declarar operação financeira real como liberada automaticamente.

## Gates
- cadeia Alembic com HEAD único em `0011_penalty_allocation_v029`;
- compilação Python e sintaxe Bash;
- auditoria de secrets e artefatos;
- verificação dos contratos de produção (Secrets, TLS, healthchecks, observabilidade);
- execução da suíte Python quando as dependências estiverem disponíveis;
- Docker Compose validado no servidor de implantação;
- UAT/E2E financeiro validado em ambiente controlado;
- backup e restauração comprovados;
- Mercado Pago Sandbox validado, incluindo assinatura e idempotência;
- revisão jurídica/regulatória aprovada antes de dinheiro real.

## Regra de GO
A release só pode receber GO operacional quando todos os gates acima forem comprovados no ambiente de implantação. Um PASS estático deste pacote não equivale a GO financeiro.

## Android
Versão `0.30.0+30`. O AAB é o artefato preferencial para Google Play; assinatura e build final devem ocorrer no ambiente com Flutter/Android SDK e keystore protegida.
