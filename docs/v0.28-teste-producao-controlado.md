# FRcaixinha 2.0 — v0.28 Teste de Produção Controlado

## Objetivo
Validar o caminho operacional de produção sem movimentar dinheiro real e sem inserir credenciais no repositório.

## Sequência
1. `./scripts/preflight_production.sh`
2. `./scripts/backup_postgres.sh`
3. `./scripts/verify_backup.sh <arquivo.dump>`
4. `./scripts/go_live_v027.sh deploy`
5. `./scripts/controlled_prod_test.sh`
6. Executar no painel do Mercado Pago o simulador de Webhook para a URL HTTPS produtiva/teste da aplicação.
7. Confirmar que o endpoint rejeita assinatura inválida e assinatura fora da janela configurada.
8. Confirmar `WebhookEvent` idempotente e que uma notificação repetida não cria lançamento duplicado.
9. Confirmar métricas/alertas internamente.
10. Fazer restauração em ambiente separado e registrar o resultado.

## Mercado Pago
A documentação atual recomenda Webhooks e validação da origem por assinatura secreta. O Mercado Pago também disponibiliza simulador para testar a entrega antes da operação. citeturn0search0turn0search4

O endpoint consulta a API do provedor para obter os dados completos do pagamento antes de confirmar a operação financeira; o payload do webhook não deve ser tratado isoladamente como prova do valor pago.

## Segurança v0.28
- HMAC `x-signature` obrigatório.
- Janela padrão de assinatura: 300 segundos.
- Eventos já processados são deduplicados por `(provider,event_id)`.
- `/metrics` permanece privado.
- Segredos continuam montados via Docker Secrets; o Docker limita o acesso aos serviços explicitamente autorizados. citeturn0search7
