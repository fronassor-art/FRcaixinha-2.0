# v0.34 — Fechamento Financeiro Mensal + Auditoria

O fechamento mensal exige reconciliação `PASS`, grava snapshot canônico e SHA-256, e passa a ser imutável pela API após `CLOSED`.

## Fluxo
1. Administrador solicita o fechamento da competência.
2. O sistema executa reconciliação.
3. Se houver divergência, o fechamento é recusado.
4. É criado snapshot dos totais e movimentos do período.
5. O snapshot recebe hash SHA-256.
6. A competência é marcada `CLOSED`.
7. Nova tentativa de fechamento retorna HTTP 409.
8. `/api/admin/finance/closings/{competence}/verify` recalcula e compara o hash.

## Segurança
O fechamento é uma operação administrativa auditável. Logs devem permitir reconstrução da sequência sem registrar segredos, tokens ou senhas, conforme orientação OWASP.

## Concorrência
A linha de fechamento é bloqueada com `FOR UPDATE`; operações financeiras concorrentes devem permanecer transacionais. Em cenários de alta concorrência, considerar isolamento SERIALIZABLE com retry.
