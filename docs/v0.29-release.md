# v0.29 — UAT/E2E Financeiro

Esta release consolida a validação do ciclo financeiro e corrige a alocação de pagamentos com multa.

## Alterações
- migration `0011_penalty_allocation_v029` adiciona `paid_penalty_amount`;
- pagamento é alocado primeiro à multa aberta e depois ao valor contratual;
- baixa idempotente mantém o Ledger sem duplicação;
- testes UAT financeiros;
- matriz automatizada de autorização;
- script `uat_v029.sh`;
- checklist GO/NO-GO.

## Não significa produção financeira liberada
A release é tecnicamente orientada a UAT. A operação com dinheiro real continua condicionada à validação jurídica/regulatória e aos testes no ambiente real.
