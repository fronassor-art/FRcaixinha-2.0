# v0.13 — Produção e Infraestrutura

## Entregas
- Dockerfile enxuto com usuário não-root.
- Compose de produção com PostgreSQL, Redis, API, worker e Nginx.
- Health check de banco em `/health/ready`.
- Logs JSON em stdout.
- `X-Request-ID` para rastreabilidade.
- Headers HTTP de segurança.
- CORS e hosts configuráveis por ambiente.
- Rate limit Redis para login, cadastro e webhook.
- Worker com lock distribuído para tarefas diárias.
- Backup PostgreSQL gzipado com retenção configurável.
- Unit/timer systemd para backup diário.

## Deploy
1. Copie `.env.production.example` para `.env` e substitua todos os segredos.
2. Configure domínio, CORS e certificados TLS em `ops/nginx/certs/`.
3. Suba com `docker compose -f docker-compose.prod.yml up -d --build`.
4. Verifique `GET /health/ready`.
5. Configure o timer de backup no host ou uma política equivalente.

## Segurança
- Não publique PostgreSQL/Redis na internet.
- Não coloque Access Token do Mercado Pago no Flutter.
- Use HTTPS no proxy reverso.
- Guarde `.env` fora do repositório.
- Faça restauração de backup em ambiente de teste periodicamente.
- Para múltiplas réplicas, prefira um processo por container e faça a replicação no orquestrador.

## Observação
A infraestrutura é preparada para produção, mas o deploy real ainda requer domínio, TLS, secrets e revisão operacional do provedor escolhido.
