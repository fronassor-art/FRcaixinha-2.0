FRcaixinha Backup

Componente de proteção de dados do projeto privado FRcaixinha 1.0.

O componente prepara pacotes verificáveis de backup do PostgreSQL e de evidências para cópia fora da VM, incluindo transporte para uma pasta selecionada no Google Drive. A operação com dados de produção depende de configuração e validação pelo responsável.

Leia a Política de Privacidade do FRcaixinha Backup.
